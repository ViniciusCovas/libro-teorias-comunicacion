# Libro interactivo de teorías de la comunicación

Libro 3D (flipbook) con 28 teorías de la comunicación: una figura interactiva, una micro película narrada y un juego por teoría.
Laboratorio HNH, Facultad de Comunicación, Universidad Anáhuac México.

Es un solo archivo, `index.html`, sin proceso de build. Vercel lo publica tal cual.
